# Static-Ordner

Für das Easter-Egg (5× auf das v2-Badge klicken):

**`easteregg.png`** — Das Bild das im DVD-Screensaver hüpft.
- Empfohlen: 200x200 px, transparenter Hintergrund (RGBA).
- Wenn die Datei fehlt: Es wird ein 🎩 Emoji als Fallback angezeigt.

Zum Erstellen aus einem JPG mit Hintergrund:
- Online: https://www.remove.bg (kostenlos)
- Oder Python: `pip install rembg pillow` → `rembg i input.jpg easteregg.png`
